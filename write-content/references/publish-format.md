# 발행 포맷 규칙 (Publish Format)

기본본(페이스북·카카오톡 동시 게시)과 확장본(sshong.com 블로그)의 포맷 규칙을 정의한다. Step 3 초안 작성과 Step 5 최종 출력에서 참조한다.

---

## 전제

홍작가의 발행 흐름은 원소스 멀티유즈다. 기본본을 페이스북과 카카오톡에 변환 없이 그대로 게시하고, 필요할 때만 블로그 확장본으로 변환한다. 따라서 **기본본은 처음부터 평문으로 작성한다.** 마크다운으로 쓴 뒤 기호를 제거하는 방식이 아니라, 평문 규칙을 초안 단계부터 적용한다.

---

## 기본본 평문 규칙 (페이스북 + 카카오톡)

### 금지 요소

| 요소 | 이유 | 대체 방식 |
|------|------|----------|
| 마크다운 기호 (#, ##, **, -, 1., >, `) | 페북·카톡에서 기호가 그대로 노출됨 | 아래 대체 방식 적용 |
| 볼드 강조 | 평문에서 렌더링 안 됨 | 문장의 위치와 내용으로 강조 |
| 표 | 평문에서 깨짐 | 문장 서술로 전환 |
| 번호·불릿 리스트 | 기호 노출 | "첫째, 둘째" 또는 문장 연결로 서술 |
| 이모지 | 홍작가 문체 기준 | 사용하지 않음 |
| 해시태그 남발 | 본문 밀도 저하 | 필요 시 본문 끝에 1~3개만 |

### 필수 요소

1. **소제목**: 부호 없는 본문형 한 줄로 쓴다. 위아래 빈 줄로 구분한다. 판단형 문장이 기본이다.
   ```
   (빈 줄)
   스킬이 없으면 매번 결과가 달라지는 이유
   (빈 줄)
   ```
2. **단락 구분**: 단락 사이 빈 줄 1줄. 한 단락은 2~4문장. 모바일 화면에서 한 단락이 5줄을 넘지 않게 한다
3. **링크**: 본문 중간이 아닌 본문 끝에 배치한다 (페이스북 도달 특성)
4. **분량**: 유형별 기본 분량을 그대로 따른다 (칼럼형 1,500~2,500자). 페이스북 롱폼 게시 기준

## 첫 2줄 후크 규칙

페이스북은 "더보기" 접힘 이전 노출 줄이 짧고, 카카오톡은 첫 화면 미리보기가 짧다. 첫 1~2줄이 나머지 전체를 읽게 만드는 관문이다.

### 규칙

1. **첫 문장 단문**: 7어절 이하. 곧바로 대상에 진입한다
2. **금지 시작**: 인사말("안녕하세요"), 자기소개, 배경 설명, 날짜·근황 나열, 기호·이모지
3. **둘째 줄까지 긴장 형성**: 아래 3가지 중 하나를 배치한다

| 후크 유형 | 패턴 | 예시 |
|----------|------|------|
| 통념의 균열 | 통념 제시 → 균열 | "AI로 글을 쓴다는 말이 유행입니다. 그런데 '쓴다'는 표현이 정확하지 않습니다." |
| 뜻밖의 관찰 | 구체 수치·현상 제시 | "지난주 강의에서 같은 질문을 세 번 받았습니다." |
| 구체적 장면 | 1인칭 장면 진입 | "어제 원고 하나를 통째로 버렸습니다." |

### 점검 질문

- 첫 2줄만 읽고 멈춰도 "그래서?"라는 질문이 생기는가
- 첫 문장을 삭제해도 글이 성립하면, 그 문장은 후크가 아니다

## 확장본 변환 규칙 (블로그)

기본본 확정 후 사용자가 요청할 때만 생성한다.

### 변환 항목

1. **소제목 위계 복원**: 본문형 소제목을 H2/H3로 전환한다. 판단형 문장 유지
2. **강조 복원**: 판단 기준 문장 1~2개를 섹션당 볼드 처리한다
3. **구조 요소 복원**: 표·번호 리스트가 내용 전달에 유리한 부분만 전환한다
4. **분량 보강**: 검색 유입을 고려해 배경·맥락 문단을 보강한다. 원본 120% 초과 시 사용자 확인
5. **도입부 조정**: 첫 2줄 후크는 유지하되, 검색 독자를 위한 범위 명시 문장을 추가할 수 있다

### 연계

sshong.com 발행용 SEO 최적화(제목 설계, 카테고리·태그, 내부 링크)까지 필요하면 write-blog 스킬로 연계한다. 이 스킬의 확장본은 구조 변환까지만 담당한다.

---

## 최종 출력 형태

- 기본본은 복사용 코드 블록(```)으로 감싸 대화창에 제공한다. 코드 블록 안은 평문 규칙이 적용된 상태여야 한다
- 확장본은 마크다운 텍스트로 제공한다
- 파일(.docx/.md)은 명시 요청 시에만 생성한다

---

## 발행 포맷 자가 점검 (기본본 출력 전)

- [ ] 마크다운 기호(#, **, -, 1., >)가 본문에 없는가
- [ ] 소제목이 부호 없는 한 줄 + 위아래 빈 줄인가
- [ ] 단락 사이 빈 줄 1줄인가
- [ ] 표·리스트·볼드·이모지가 없는가
- [ ] 첫 문장이 7어절 이하 단문인가
- [ ] 첫 2줄 안에 후크(균열·관찰·장면)가 있는가
- [ ] 링크가 본문 끝에 있는가
