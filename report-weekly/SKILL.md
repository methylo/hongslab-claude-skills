# report-weekly

주간 업무 보고를 만든다. 월간 모니터링(report-monitoring)이 실적·현황 분석이라면, 이 스킬은 "지난주 한 일 + 이번주 할 일 + 막힌 것"을 공유하는 경량 보고에 집중한다. 핵심 가치는 메모를 정형 양식으로 바꾸는 반복성이다.

## 공용 기준

문체·수치 표기·금지어·개인정보·저장 규칙은 `report-suite`의 공용 기준을 상속한다.

- 작성 규칙 → `../report-suite/references/report-standards.md`
- 저장 규칙 → `../report-suite/references/output-formats.md`

`report-suite` 없이 단독 사용 시에는 아래 최소 규칙으로 진행한다. **개인정보 가명 처리 / 종결어미 통일 / 한 문장 40자 이내 / 입력에 없는 수치·성과 생성 금지 / 금지어(혁신적인·매우·상당히) 금지.**

## 입력

- 한 주간 업무 메모 (불릿·키워드 가능)
- 완료 항목 / 진행 항목 / 계획 항목 (구분 안 되어 있어도 됨)
- 성과·수치 (있으면)

입력이 뒤섞인 메모뿐이어도 진행한다. 완료·진행·계획 구분은 스킬이 시제로 판단한다.

## 워크플로우 (3단계)

1. 분류 — 메모를 완료(한 일) / 계획(할 일) / 이슈로 가른다
2. 배치 — 4블록에 항목을 넣고 다음 주 할 일은 우선순위순으로 정렬한다
3. 정리·검증 — 시제를 통일하고(한 일=과거, 할 일=미래) 완성 조건을 점검한다

## 출력 포맷 (4블록 고정)

```
# {YYYY-MM-DD ~ MM-DD} 주간 업무 보고

## 1. 이번 주 한 일
- (완료 항목. 성과·수치 있으면 병기)

## 2. 다음 주 할 일
- (계획 항목. 우선순위순)

## 3. 이슈·리스크
- (막힌 것·도움 필요한 것. 없으면 "없음")

## 4. 특이사항
- (공유할 메모. 없으면 블록 생략)
```

## 규칙

- 한 일은 완료된 것만. 진행 중인 항목은 "○○ 진행 중(70%)" 형태로 한 일 블록에 명시하거나 다음 주 할 일로 넘긴다
- 입력에 없는 성과·수치를 임의 생성하지 않는다
- 항목은 명사형으로 끝맺어 스캔하기 쉽게 한다 (예: "강의안 초안 완성")
- 매주 동일 양식 유지. 블록 순서·제목 변경 금지

## 완성 조건 (자가 점검)

공용 기준의 자가 평가 루프에 더해 이 스킬 고유 항목을 점검한다.

- 한 일(과거)과 할 일(미래)의 시제가 섞이지 않았는가
- 이슈 블록이 비어 있으면 "없음"으로 명시했는가
- 4블록의 순서·제목을 바꾸지 않았는가

## 저장

- 단발: 대화창 텍스트로 제공
- 누적 관리: `주간보고-YYMMDD.md`로 저장 (규칙은 `output-formats.md`)
