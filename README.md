# HONGS LAB Claude Skills

홍작가(홍순성)가 1인 기업·콘텐츠 제작·강의용으로 설계한 Claude 스킬 모음입니다. 글쓰기, 책쓰기, 강의 자료, 리서치 등의 작업을 자동화합니다.

## 다운로드 방법

### 방법 1. ZIP 전체 다운로드 (권장)

1. 이 페이지 상단의 초록색 `Code` 버튼 클릭
2. `Download ZIP` 클릭
3. 압축 해제

### 방법 2. 개별 스킬 폴더 다운로드

원하는 스킬 폴더 클릭 → 파일 화면에서 `Download raw file` 아이콘 클릭

## 사용 방법

1. 압축 해제한 스킬 폴더를 Claude 채팅창에 업로드합니다.
2. 트리거 키워드로 호출합니다.

```
예시
"글쓰기 스킬로 작성해줘"
"write-content 스킬로 정리해줘"
```

각 스킬의 트리거 키워드는 해당 폴더의 `SKILL.md` 파일 상단에서 확인할 수 있습니다.

## 포함된 스킬

### 글쓰기

| 스킬명 | 용도 |
|--------|------|
| `write-content` | 단편 콘텐츠 작성 (칼럼·뉴스레터·보고서 등) |
| `voice-note-writing` | 음성 전사문·긴 구어체 메모를 칼럼 한 편으로 완성 |

### 문체 기준

| 스킬명 | 용도 |
|--------|------|
| `hong-voice-reference` | 문체 정본 참조 라이브러리. 다른 스킬이 호출해서 쓴다 |

`hong-voice-reference`는 사용자가 직접 호출하는 스킬이 아닙니다. `voice-note-writing`이 원고를 쓰는 동안 문체 기준을 읽어오는 참조 라이브러리입니다. **두 폴더를 함께 올려야 정상 동작합니다.** `hong-voice-reference` 없이 `voice-note-writing`만 올리면 축약된 폴백 기준으로만 작동합니다.

### 편집·퇴고

| 스킬명 | 용도 |
|--------|------|
| `edit-writing-room` | 완성 원고를 독자·편집자 두 역할로 갈라 검토하고 다듬기 (3인 편집실) |

스킬은 점진적으로 추가될 예정입니다.

## 음성 글쓰기 사용법

`voice-note-writing`은 다른 스킬과 사용 방식이 조금 다릅니다. 정리된 주제나 개요 없이, 말한 내용을 그대로 넣습니다.

```
예시
"음성 글쓰기로 작성해줘"
"방금 말한 걸 글로 써줘"
"주저리주저리 말했는데 내가 무슨 말을 하려는지 찾아줘"
```

반복, 말을 되돌린 자리, 후반의 정정을 중심 생각을 찾는 단서로 씁니다. 본문에 섞인 편집 요청("사례도 좀 넣어줘")은 글의 주장과 분리합니다. 결과는 요약이나 메모가 아니라 제목과 문단을 갖춘 1,300~1,500자 원고입니다.

## 스킬이란

Claude Skills는 특정 작업의 워크플로우를 코드화한 지시문 모음입니다. 매번 같은 작업을 설명할 필요 없이, 스킬 폴더를 업로드하고 트리거 키워드로 호출하면 동일한 품질의 결과를 반복적으로 얻을 수 있습니다.
