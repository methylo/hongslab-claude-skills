# HONGS LAB Claude Skills

홍작가(홍순성)가 1인 기업·콘텐츠 제작·강의용으로 설계한 Claude 스킬 모음입니다. 글쓰기, 책쓰기, 강의 자료, 리서치 등의 작업을 자동화합니다.

## 다운로드 방법

### 방법 1. ZIP 전체 다운로드 (권장)

1. 이 페이지 상단의 초록색 `Code` 버튼 클릭
2. `Download ZIP` 클릭
3. 압축 해제

### 방법 2. 개별 스킬 폴더 다운로드

원하는 스킬 폴더 클릭 → 파일 화면에서 `Download raw file` 아이콘 클릭

## 사용 방법

1. 압축 해제한 스킬 폴더를 Claude 채팅창에 업로드합니다.
2. 트리거 키워드로 호출합니다.

```
예시
"글쓰기 스킬로 작성해줘"
"write-content 스킬로 정리해줘"
```

각 스킬의 트리거 키워드는 해당 폴더의 `SKILL.md` 파일 상단에서 확인할 수 있습니다.

## 포함된 스킬

### 보고서 (report-suite 묶음)

보고서 스킬은 **묶음 단위로 내려받는다.** `report-suite`가 유형을 판별하는 진입점이자 안내판이고, 공용 작성 기준(문체·수치·금지어·개인정보·저장 규칙)을 한곳에서 관리한다.

| 스킬명 | 용도 | 출력 | 상태 |
|--------|------|------|------|
| `report-suite` | 보고서 10종 진입점·유형 판별 라우터 | — | 사용 가능 |
| `report-daily` | 일일 업무 보고 | 텍스트 | 준비 중 |
| `report-weekly` | 주간 업무 보고 (4블록 고정) | 텍스트/.md | 사용 가능 |
| `report-monitoring` | 월간 모니터링 보고 (4단계) | .docx/.hwpx | 사용 가능 |
| `report-annual` | 분기·연간 결산 보고 | .docx | 준비 중 |
| `meeting-minutes` | 회의록 (결정사항·액션아이템) | .md/.docx | 사용 가능 |
| `report-trip` | 출장·현장 방문 보고 | 텍스트/.docx | 준비 중 |
| `report-incident` | 이슈·장애·민원 경위 보고 | 텍스트/.docx | 준비 중 |
| `report-result` | 사업 결과·정산 보고 | .docx/.hwpx | 준비 중 |
| `research-report` | 리서치·분석 보고서 (5섹션) | .docx | 사용 가능 |
| `chungcheong-report` | 공공 표준 양식 공고문·보고서 (7섹션) | .hwpx | 사용 가능 |

**사용법**

```
"보고서 써줘"           → report-suite가 유형을 물어보고 배정
"주간 보고 정리해줘"     → report-weekly 직접 실행
"이번 달 모니터링 보고서" → report-monitoring 직접 실행
```

유형이 분명하면 라우터를 거치지 않고 바로 해당 스킬이 실행된다.

**개별 스킬만 받아 쓸 때**는 공용 기준 파일(`report-suite/references/`)이 없으므로 각 스킬에 포함된 "최소 규칙"으로 동작한다. 전체 기준을 적용하려면 `report-suite` 폴더를 함께 올린다.

### 글쓰기

| 스킬명 | 용도 |
|--------|------|
| `write-content` | 단편 콘텐츠 작성 (칼럼·뉴스레터·기고문 등) |

스킬은 점진적으로 추가될 예정입니다.

## 스킬이란

Claude Skills는 특정 작업의 워크플로우를 코드화한 지시문 모음입니다. 매번 같은 작업을 설명할 필요 없이, 스킬 폴더를 업로드하고 트리거 키워드로 호출하면 동일한 품질의 결과를 반복적으로 얻을 수 있습니다.
