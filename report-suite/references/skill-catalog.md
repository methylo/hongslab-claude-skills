# 보고서 10종 명세 카드

각 스킬의 입력·출력·분량이다. 사용자가 "이 보고서는 뭘 준비해야 하냐"고 물으면 해당 카드를 제시한다.

---

## 1. report-daily — 일일 업무 보고 (준비 중)

- **입력** 하루 업무 메모
- **출력** 3블록 (오늘 한 일 / 내일 할 일 / 특이사항)
- **분량** 반 페이지 이내
- **임시 대응** `report-weekly`를 기간 하루로 축소해 사용

## 2. report-weekly — 주간 업무 보고

- **입력** 한 주 업무 메모 (불릿·키워드 가능, 완료/진행/계획 구분 안 되어 있어도 됨)
- **출력** 4블록 (이번 주 한 일 / 다음 주 할 일 / 이슈·리스크 / 특이사항)
- **분량** 1페이지
- **특징** 양식 100% 고정. 매주 입력만 바꿔 반복 생성

## 3. report-monitoring — 월간 모니터링 보고

- **입력** 월간 실적 데이터(표·수치·메모), 이전 달 보고서(있으면)
- **출력** 4단계 (현황 요약 / 주요 이슈 / 조치 사항 / 다음 달 계획)
- **분량** A4 1~2페이지
- **특징** 전월 대비 비교, 이슈마다 근거 수치 병기. .docx/.hwpx 저장

## 4. report-annual — 분기·연간 결산 보고 (준비 중)

- **입력** 기간 실적 데이터, 목표 대비 달성률, 예산 집행 내역
- **출력** 5단계 (기간 개요 / 목표 대비 실적 / 주요 성과 / 미달 항목과 원인 / 차기 계획)
- **분량** A4 3~5페이지
- **임시 대응** `report-monitoring`을 기간 확장해 사용

## 5. meeting-minutes — 회의록

- **입력** 회의 메모·녹취·자동 전사본 (클로바노트·Zoom·Teams 결과물)
- **출력** 4블록 (회의 개요 / 결정사항 / 액션아이템 표 / 논의 메모)
- **분량** 1~2페이지
- **특징** 담당·기한을 표로 정리. 근거 없으면 "미정"

## 6. report-trip — 출장·현장 방문 보고 (준비 중)

- **입력** 방문 일정·장소·면담자, 현장 메모, 경비 내역
- **출력** 5블록 (출장 개요 / 방문 경과 / 확인 사항 / 후속 조치 / 경비 정산)
- **분량** 1~2페이지
- **임시 대응** `meeting-minutes`에 방문지·경비 항목을 추가해 사용

## 7. report-incident — 이슈·장애·민원 보고 (준비 중)

- **입력** 발생 시각·경위 메모, 영향 범위, 조치 내역
- **출력** 4단계 (발생 경위 / 영향 범위 / 조치 사항 / 재발 방지 대책)
- **분량** 1페이지
- **특징** 시각 단위 타임라인 필수. 책임 소재보다 사실 관계 우선
- **임시 대응** `report-monitoring`의 4단계를 치환해 사용

## 8. report-result — 사업 결과 보고 (준비 중)

- **입력** 사업 계획서, 추진 실적, 성과 지표, 예산 집행 내역
- **출력** 5섹션 (사업 개요 / 추진 실적 / 성과 분석 / 예산 집행 / 향후 계획)
- **분량** A4 3~10페이지
- **임시 대응** `research-report`의 5섹션을 치환해 사용

## 9. research-report — 리서치·분석 보고서

- **입력** 리서치 주제, 조사 범위, 활용 목적(강의·기획·의사결정)
- **출력** 5섹션 (요약 / 배경·문제 정의 / 핵심 발견 / 시사점·제언 / 출처 부록)
- **분량** A4 3~7페이지
- **특징** 웹 검색으로 근거 수집, 출처 표기 필수. .docx 템플릿 내장

## 10. chungcheong-report — 공공 표준 양식 보고서·공고문

- **입력** 사업 정보(PDF·텍스트·메모)
- **출력** 7섹션 (추진 배경 / 사업 개요 / 지원 대상 / 진행 절차 / 평가 기준 / 유의 사항 / 문의처)
- **분량** A4 2~4페이지
- **특징** 4계층 기호(□·◦·-·◈) 자동 적용, 추진 배경은 등급 A 공공통계 인용. `.hwpx` 빌드 스크립트 포함
