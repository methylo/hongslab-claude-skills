# 보고서 저장 규칙

## 포맷 선택

내용이 확정된 뒤에 묻는다. 초안 단계에서 미리 묻지 않는다.

> 보고서를 파일로 저장할까요?
> - **워드(.docx)** — MS 워드에서 편집
> - **한글(.hwpx)** — 한컴오피스에서 편집
> - **저장 안 함** — 위 텍스트를 복사해서 사용

제출처가 공공기관이면 .hwpx를, 기업·내부 공유면 .docx를 먼저 제안한다.

## 포맷별 처리

| 포맷 | 처리 | 비고 |
|---|---|---|
| `.md` | 대화창 텍스트 그대로 또는 파일 저장 | 주간·회의록 등 경량 보고의 기본값 |
| `.docx` | `docx` 스킬로 생성 | 표·머리말·페이지 번호 지원 |
| `.hwpx` | `hwpx` 스킬로 생성 | 공공기관 제출용 기본값 |
| 공공 표준 양식 | `chungcheong-report`의 빌드 스크립트 | 7섹션 고정 양식일 때만 |

## 파일명 규칙

| 유형 | 형식 | 예시 |
|---|---|---|
| 일일 | `YYMMDD 일일업무보고` | `260818 일일업무보고.docx` |
| 주간 | `주간보고-YYMMDD` | `주간보고-260818.md` |
| 월간 | `YYYY년 MM월 [제목]` | `2026년 8월 활동지원서비스 모니터링.docx` |
| 분기·연간 | `YYYY년 N분기 [제목]` | `2026년 2분기 사업실적보고.docx` |
| 회의록 | `YYMMDD [회의명] 회의록` | `260818 운영위원회 회의록.md` |
| 사건형 | `YYMMDD [사건명] 보고` | `260818 시스템장애 경위보고.docx` |
| 리서치 | `[주제] 리서치보고서-YYMMDD` | `AI교육트렌드 리서치보고서-260818.docx` |

날짜는 보고 대상 기간의 종료일을 쓴다. 작성일이 아니다.

## 저장 위치

- 단발 작업: 현재 작업 폴더
- 반복 보고: 보고 유형별 폴더에 누적 (`주간보고/`, `월간보고/`)
- 회의·컨설팅: 해당 프로젝트 폴더 하위

## 저장 후 안내

같은 데이터로 만들 수 있는 변형을 함께 제시한다.

- "짧게 요약해줘" → 반 페이지 요약본
- "발표용으로 바꿔줘" → 슬라이드용 불릿
- "건의서로 바꿔줘" → 현황-문제점-개선안-기대효과 구조
