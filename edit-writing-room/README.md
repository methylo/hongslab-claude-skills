# 3인 편집실 (edit-writing-room)

완성 원고를 **독자**와 **편집자** 두 자리로 갈라 검토하고 다듬는 스킬입니다.

## 왜 세 자리인가

글 한 편에는 작가·독자·편집자 세 자리가 필요한데, AI에게 맡기면 한 에이전트가 세 자리를 혼자 차지합니다. 쓰고, 스스로 읽고, 스스로 잘 썼다고 판단합니다.

이 스킬은 그 자리를 다시 갈라놓습니다.

| 자리 | 누가 맡는가 | 결정하는 것 |
|---|---|---|
| 작가 | 사람 | 무엇을 쓸지, 경험을 어디까지 공개할지, 발행 여부 |
| 독자 | 서브에이전트 | 어디서 막혔는지 (수정 권한 없음) |
| 편집자 | 서브에이전트 | 어떻게 고칠지 (사실·경험 추가 권한 없음) |

## 호출 축 세 가지

| 축 | 값 | 기본값 |
|---|---|---|
| 역할 | 독자 · 편집자 · 편집실 · 병렬 | 편집실 |
| 출력 | 제안 · 선택반영 · 전체반영 | 제안 |
| 강도 | 최소 · 표준 · 구조 | 표준 |

기본은 **제안 모드**입니다. 원고 전문을 고쳐서 내지 않고, 우선 수정 세 가지를 `현재 문장 → 수정 방향 문장 → 이유`로 제시합니다. 전문 수정본은 `반영해줘`를 받은 뒤에 냅니다.

## 쓰는 법

```
이 원고를 3인 편집실로 검토해줘.
독자 검토만 해줘. 문장은 고치지 마.
편집자만 불러서 최소 강도로 봐줘.
1번과 3번만 반영해줘.
```

## 문체 기준

이 스킬은 `hong-voice-reference`라는 별도 문체 정본을 호출해 동작합니다. 그 정본은 홍작가 개인 기준이라 이 저장소에 포함되지 않습니다.

정본이 없으면 **폴백 모드**로 돌아가며, `SKILL.md`에 내장된 `편집 기준 최소 카드`만으로 편집자 단계를 끝냅니다. 중단하지 않습니다.

자기 문체 정본을 쓰려면 `SKILL.md`의 조달표대로 1층(시선·어조) · 2층(단어) · 3층(AI 흔적) · 4층(승인 원문)에 해당하는 파일 경로를 넘기면 됩니다.

## 포함된 도구

| 파일 | 용도 |
|---|---|
| `scripts/self-check.py` | 스킬 내부 정합성 검사 (버전·조달 규칙 대칭·회귀) |
| `scripts/scan-traces.py` | AI 흔적 후보 추출. 사전을 복사하지 않고 실행 시점에 정본 §10을 파싱한다 |

두 도구 모두 판정하지 않습니다. 발견만 하고 판단은 편집자가 합니다.
