# 보고서 작성 스타일 가이드 (충청연수원·중소벤처기업진흥공단 표준 양식)

## 1. 4가지 핵심 원칙

| 원칙 | 기준 | 위반 시 처리 |
| --- | --- | --- |
| A4 우측 채움 | 80~95자 한 항목 | 3줄 초과 시 분리 또는 표로 전환 |
| 표 우선 활용 | 5줄 이상 나열 시 표 검토 | 4열·5열·3열 표준 표 사용 |
| 계층 기호 + 들여쓰기 | □ → ◦ → - → ◈ → * | paraPr 24·25·26로 자동 |
| 통계 출처 등급 A | 통계청 등 정부 공식 자료 | 등급 C 자료 단독 인용 금지 |

## 2. 7섹션 표준 구조

머리말 → 1 추진 배경 → 2 사업 개요 → 3 지원 대상·규모 → 4 진행 절차 → 5 평가 기준·가점 → 6 유의 사항 → 7 문의처

## 3. 계층 기호 사용 위치

| 위치 | 기호 | 예시 |
| --- | --- | --- |
| 섹션 헤더 | 숫자 + 음영 | `1 추진 배경` |
| 대제목 | `□` | `□ 추진 필요성` |
| 중제목 | `◦` | `◦ 통계청 자료에 따르면…` |
| 세부 | `-` | `- 전년 대비 6.8%p 감소` |
| 강조 | `◈` | `◈ 휴·폐업 기업 제외` |
| 각주 | `*` | `* 출처: 통계청, 2025` |

## 4. 추진 배경 4단 구조

1. 현황 진단 — 정량 데이터로 시작
2. 문제 정의 — 격차·결손을 한 문장으로 압축
3. 사업 필요성 — 본 사업이 어떻게 대응하는지 1~2줄
4. 출처 표기 — `*` 각주로 통계명·발표연도

## 5. 금지어 목록 (0건 보장)

| 금지 표현 | 대체 표현 |
| --- | --- |
| 혁신적인·획기적인 | 새로운·기존과 다른 |
| 완벽한 | 충실한·전 영역의 |
| 매우 | (삭제) |
| 쉽게·빠르게 | (구체 행동·시간으로 대체) |
| ~할 수 있습니다 + 추상명사 | (행동 동사로 직접 기술) |

## 6. 통계 출처 등급별 우선순위

| 등급 | 출처 |
| --- | --- |
| A (우선) | 통계청 KOSIS, 관세청, 산업통상자원부, 한국은행 |
| B (보조) | KDI, KIET, 한국직업능력연구원, 대한상의 |
| C (참고만) | 언론 기사, 기업 IR, 블로그 |

## 7. 표 헤더·본문 스타일

- 헤더 셀: 배경 #DAEEF3, 볼드 10pt, 가운데 정렬
- 본문 셀: 흰 배경, 10pt
  - 텍스트 항목: 좌측 정렬
  - 숫자·구분·연락처: 가운데 정렬

## 8. 종결어미 규칙

- 공고문 본문: 명사형 종결 ("…한다", "…할 것")
- 보고서 본문: ~합니다체
- 한 문서 내 혼용 금지

## 9. 자리표시자 처리

빈 템플릿의 자리표시자(`[…]`)는 다음 원칙으로 처리한다.

- 사용자가 정보 제공한 항목: 즉시 사실로 교체
- 사용자가 정보 미제공한 항목: `[…]` 유지 + 미교체 목록을 사용자에게 보고
- 자리표시자를 임의로 삭제하지 않는다 (검토 누락 방지)
