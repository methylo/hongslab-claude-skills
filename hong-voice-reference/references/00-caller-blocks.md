# 00 호출하는 쪽 설정 (설정 전용)

> `v1.6.0` · 갱신 2026-09-22 · 정본: `hong-voice-reference` 스킬. 이 파일을 직접 고치지 않는다.

> 이 파일은 글 작업 중에 읽지 않는다. 다른 스킬을 고칠 때만 본다.

---

## A. 각 스킬에 넣을 호출 블록

아래 블록을 해당 스킬의 SKILL.md에 그대로 넣는다.

```text
### 문체 기준 로드 (해당 대화에서 1회)

1. Skill 도구로 `hong-voice-reference`를 호출한다.
2. 반환된 `Base directory`를 BASE로 두고 필요한 층만 읽는다.

   {BASE}/references/01-voice.md         초안·리라이팅 진입 전 (필수)
   {BASE}/references/02-glossary.md      단어 선택 단계 (필수)
   {BASE}/references/03-anti-traces.md   출력 직전 점검 (필수)
   {BASE}/references/04-examples.md      문체 판정이 갈릴 때만
   {BASE}/references/05-corrections.md   같은 표현을 두 번 이상 고쳤을 때만

3. 같은 대화에서 이미 읽은 파일은 다시 읽지 않는다.
4. 층 순서를 지킨다. 1층 → 2층 → 3층.
5. 호출이 실패하면 아래 `문체 최소 카드`로 진행하고,
   산출물 말미에 실행 모드를 한 줄로만 밝힌다.
```

이 표는 **전환을 마친 스킬만** 싣는다. 계획·검토 중인 스킬은 넣지 않는다. 상태 열이 전부 `완료`라야 이 표를 보고 버전 드리프트를 판정할 수 있다.

전환 대상이 아닌 경우는 아래에 사유만 남긴다.

- **채널 스킬 4종** (`write-blog`·`write-facebook`·`write-brunch`·`write-essay`) — 직접 호출하지 않는다. `voice-note-writing` Step 9가 문체 3층을 대신 책임진다
- **`edit-deai`** — `edit-hongstyle` 강도 `가볍게`로 흡수됐다. 자체 상투어 사전과 흔적 지수는 §10·§11로 이관을 마쳤다
- **책쓰기 계열** — 위 2종만 본문 문체를 만든다. `book-planning`은 기획 문서 문체를 쓰므로 대상이 아니고, `book-research`·`book-citation`·`book-feedback-reader`·`book-feedback-editor`·`book-orchestrator`는 본문을 쓰지 않으므로 대상이 아니다. 책 프로젝트의 문체 우선순위 정본은 `book-orchestrator`의 `references/pipeline-contract.md` §2다

`edit-writing-room`의 v3.2.0~v3.6.0 변경 중 호출 규격에 영향을 주는 것은 아래와 같다. 다른 스킬을 전환할 때 참고한다.

| 항목 | 내용 |
|---|---|
| 강도별 조달 | 최소 `01·03` / 표준 `01·02·03` / 구조 `01·02·03·04`. 서브에이전트는 새 문맥이라 `이미 읽은 파일은 다시 읽지 않는다`가 발동하지 않으므로, 넘긴 경로는 호출마다 처음부터 읽힌다 |
| 04-examples | 이 파일의 `문체 판정이 갈릴 때만` 규격대로 조건부. 구조 강도에서만 미리 넘기고, 최소·표준에서는 편집자가 `판정 보류: (위치)`로 남기면 호출한 쪽이 04를 직접 읽어 해소한다 |
| 05-corrections | 경로로 넘기지 않는다. 호출한 쪽이 읽어 원고와 겹치는 항목만 본문으로 발췌해 넘긴다 (3,405자로 작다) |
| 정본 건강 점검 | STEP 0에서 `scripts/validate.py`를 1회 실행하고, 실패해도 멈추지 않고 한 줄로만 보고한다 |
| 폴백 카드 | §C를 그대로 옮기고 호출하는 쪽 고유 보강은 카드 본문에 섞지 않는다. 섞으면 다음 동기화 때 원본이 갈린다 |

`edit-writing-room`만 처리가 다르다. 서브에이전트는 `Skill` 도구를 쓰지 못하므로 정본을 스스로 호출할 수 없다. 다만 **절대 경로를 받으면 파일은 직접 읽는다.** 메인이 호출해 Base directory를 확보한 뒤 절대 경로를 넘긴다. 3층 본문(57KB)을 프롬프트에 복사하지 않는다.

## C. 문체 최소 카드 (폴백)

`hong-voice-reference` 호출이 실패했을 때만 쓴다. 각 스킬 SKILL.md 하단에 이 블록을 둔다.

```text
어조    가르치지 않되 이끈다. 설득보다 납득
시점    확인된 경험만 1인칭. 없으면 관찰·자료·개념에서 시작
전개    경험형: 실행·장면 → 기대 → 어긋남 → 현재 판단
        개념형: 문제 상황 → 개념 → 판단 기준 → 적용
리듬    같은 길이·역할 문장 3연속이면 점검. 문단 길이 균일화 금지
        단문 7어절 이하 / 중문 8~13 / 장문 14 이상 (승인 원문 실측). 진단 눈금이지 규격 아님
종결    채널이 정한다. 공식 문서는 축약형 풀어쓰기, 페이스북·에세이는 축약형 허용
어휘    기능·도구보다 기준·역할·구조·설계·판단
소제목  기능명 금지, 행동·판단 문장
볼드    평문 기본본 사용 안 함. 블로그 확장본만 섹션당 1~2개
마무리  현재 판단·행동·상태·남은 질문 중 하나. 요약·행동 촉구 금지
금지어  혁신적인·획기적인·완벽한·강력한·효과적으로·이를 통해·결과적으로·좋은 질문입니다
조건부  매우·쉽게·빠르게·상당히·꽤 — 실제 체감·전후 비교를 나타내면 유지
        ~할 수 있습니다 — 가능 조건이 분명하면 유지, 근거 없는 가능성만 교체
상투어  ~라고 할 수 있다·~인 것으로 보인다·중요한 역할을 한다·다양한
        ~을 통해·급변하는 시대·빼놓을 수 없다·결론적으로 ~이다
일반론  구체 사례·수치 없는 문장은 대신 채우지 않고 `구체화 필요: 위치`로 표시
교체    지운 자리는 조건·수치·비교 기준·구체 사례·실제 행동·판단으로 채운다
보존    사용자가 직접 쓴 표현, 실제 불확실성, 판단 강도, 수치·인용·고유명사
역점검  변경률 30% 초과 시 사실·문체 소유감 재대조. 50% 초과 시 근거 있는 구간만 남김
```
