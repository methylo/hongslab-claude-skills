# 홍작가 보이스 레퍼런스

홍작가 명의로 나가는 한국어 글의 문체 기준 정본이다. 이 스킬은 글을 쓰지 않는다. 기준만 제공한다.

## 파일과 읽는 시점

호출한 스킬은 아래 `Base directory`를 기준으로 필요한 층만 읽는다. 전부 읽지 않는다.

| 파일 | 층 | 읽는 시점 |
|---|---|---|
| `references/01-voice.md` | 1층 시선·어조·논리·리듬·마무리 | 초안 작성 전, 리라이팅 전 (필수) |
| `references/02-glossary.md` | 2층 단어·문장 선택 | 단어 교체 단계 (필수) |
| `references/03-anti-traces.md` | 3층 AI 흔적·금지어·계량 | 출력 직전 점검 (필수) |
| `references/04-examples.md` | 공통 승인 원문 | 문체 판정이 갈릴 때만 |
| `references/05-corrections.md` | 공통 교정 이력 | 같은 표현을 두 번 이상 고쳤을 때만 |

같은 대화에서 이미 읽은 파일은 다시 읽지 않는다.

## 적용 순서

```text
1층 시선·구조  →  2층 단어  →  3층 흔적 제거
```

순서를 지킨다. 시선과 구조가 정리되기 전에 단어나 흔적부터 만지면 같은 문장을 두 번 고치게 된다.

## 우선순위

```text
사실·원문
→ 현재 사용자 지시
→ 승인된 경험·사용자 표현
→ 04-examples · 05-corrections     ← 규칙 3층보다 위
→ 프로젝트별 기준 (책·연재·기관 사전)
→ 채널 기준 (블로그 SEO·페이스북 호흡·책 챕터 구조)
→ 01-voice
→ 02-glossary
→ 03-anti-traces
```

채널 스킬은 형식을 정하고, 이 스킬은 문체를 정한다. 충돌하면 위 순서를 따른다.

## 장르 예외

논문·학술 원고는 학술 규범(`~한다`체, 헤지 표현 보존, 인용 형식)이 보이스보다 앞선다. 이때는 3층만 적용하고 1·2층은 어휘 수준으로만 참고한다.

## 절대 규칙

- 사실·수치·인용·출처·고유명사·주장 강도는 바꾸지 않는다
- 확인되지 않은 경험·사례·발화를 만들지 않는다
- 이 스킬의 파일을 실행 중에 고치지 않는다. 고쳐도 남지 않는다
- 기준이 규칙과 승인 원문 사이에서 갈리면 `04-examples.md`의 실제 문단을 따른다

## 갱신 절차

이 스킬이 정본이다. 외부 저장소에 별도 사본이나 백업을 두지 않는다. 볼트나 다른 폴더에서 옛 사본이 발견되면 정본으로 읽지 말고 지운다.

### 교정 수집 (글 작업 중)

홍작가가 결과물의 표현을 직접 고치면, 그 자리에서 파일을 수정하지 않고 **작업 말미에 교정 카드 한 줄만 대화창에 출력한다.**

```text
[교정] 수정 전 → 수정 후 | 이유 | 채널
```

파일을 고치지 않는 이유는 두 가지다. 스킬 파일은 세션이 끝나면 초기화되므로 실행 중 편집은 남지 않는다. 그리고 글 작업 도중에 기준을 바꾸면 같은 글 안에서 기준이 두 개가 된다.

### 반영 (별도 작업)

교정 카드가 쌓이면 별도 세션에서 아래를 실행한다.

1. 모은 카드를 `references/05-corrections.md` 교정 이력 표에 추가한다
2. 같은 항목이 3회에 도달하면 해당 층 파일(01·02·03)로 승격하고 `승격` 열에 표시한다
3. `references/` 각 파일 머리의 `갱신` 날짜를 고친다
4. `.skill`을 다시 패키징해 설치한다
5. `version`을 올리고 아래 변경 이력에 한 줄 남긴다

3·5단계를 빠뜨리면 어느 파일이 언제 것인지 판별할 수 없게 된다.

## 무결성 점검

`scripts/validate.py`를 실행하면 파일 존재·헤더 표기·절 번호 참조·내부 모순을 정적으로 검사한다. 갱신 후 반드시 1회 실행한다.

```bash
python3 scripts/validate.py
```

## 호출하는 쪽 설정

각 글쓰기 스킬에 넣을 호출 블록과 폴백 카드는 `references/00-caller-blocks.md`에 있다. 이 파일은 설정용이며 글 작업 중에는 읽지 않는다.
