# 음성 인식 교정 사전

비정형 음성 전사문에서 반복되는 오인식을 기록한다. 이 사전은 기계적 치환 목록이 아니다. 같은 대화, 프로젝트, 제품명, 문장 의미가 교정을 뒷받침할 때만 적용한다.

## 교정 원칙

1. 제품명·인명·기관명·수치는 문맥 근거가 있을 때만 고친다.
2. 한 번 나온 오류는 `관찰 후보`로 두고 공용 치환 규칙으로 만들지 않는다.
3. 같은 오인식이 여러 작업에서 반복되거나 사용자가 직접 교정하면 `확인됨`으로 승격한다.
4. 교정 결과에 따라 글의 사실이나 판단이 달라지면 사용자에게 묻는다.
5. 중심 논지에 필요 없는 불확실한 표현은 자연스럽게 우회할 수 있다.
6. 원문의 말투와 어휘 선택은 오인식과 구분한다. 문법적으로 거칠다는 이유만으로 사용자의 말을 다른 개념으로 바꾸지 않는다.

## 상태 값

| 상태 | 의미 | 처리 |
|---|---|---|
| 확인됨 | 사용자 교정 또는 여러 문맥에서 반복 확인 | 조건이 맞으면 자동 교정 |
| 문맥형 | 특정 대화·프로젝트에서만 명백 | 해당 문맥에서만 교정 |
| 관찰 후보 | 한 번 나타났거나 여러 해석이 가능 | 자동 교정 금지 |

## 현재 항목

| 전사 표현 | 교정 후보 | 상태 | 적용 조건 |
|---|---|---|---|
| 클라우드 스킬 | 클로드 스킬 | 문맥형 | 같은 대화에서 Claude 또는 클로드의 스킬 기능을 말하고 있을 때 |
| 사래 농도 | 사례 농도 | 관찰 후보 | 앞뒤 문장이 사례를 더 많이 넣어 달라는 편집 요청일 때만 후보로 봄 |

## 항목 추가 형식

```text
전사 표현:
교정 표현:
상태: 확인됨 / 문맥형 / 관찰 후보
처음 확인한 맥락:
반복 확인 횟수:
사실 변경 위험: 낮음 / 중간 / 높음
비고:
```

## 자동 교정 금지 항목

다음 항목은 한 글 안에서 문맥이 명백해 보여도 사실 확인 없이 고정 치환하지 않는다.

- 사람 이름과 기관명
- 날짜, 시간, 금액, 비율, 횟수
- 책·강의·프로젝트의 공식 제목
- 서로 다른 제품이 실제로 존재하는 제품명
- 인용문 안의 핵심 단어

이 사전은 음성 오인식만 다룬다. 사용자가 선호하거나 피하는 글쓰기 표현은 `hong-voice-reference` 스킬의 `02-glossary.md`에서 관리한다.
