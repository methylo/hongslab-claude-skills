# 근거 보강 관문

이 문서는 음성에서 저자의 판단을 먼저 잠근 뒤, 그 판단에 꼭 필요한 조사만 연다. 조사량을 늘리는 것이 목적이 아니다.

## 1. 조사 필요 판정

다음이 원고의 핵심을 지지하면 `research.needed: true`로 둔다.

- 통계·비율·기간·금액
- 기관·전문가·연구 결과
- 최신 제품 기능·가격·플랜·접근성
- 제3자의 사례를 일반화한 주장
- 독자가 따라 할 설치·설정·사용 절차
- `많은 사람`, `대부분`, `더 빠르다`처럼 외부 확인이 필요한 비교

다음은 기본적으로 조사하지 않는다.

- 사용자가 직접 밝힌 경험과 현재 판단
- 원문에 있는 감정·기대·불편
- 개인 작업 방식의 변화
- 외부 사실 없이도 성립하는 경험형 칼럼

완료 기준: 조사 여부와 이유가 한 문장으로 설명되고 `claims_to_verify`가 비어 있거나 명시돼 있다.

## 2. 판단 선행 원칙

조사 전에 다음을 잠근다.

```text
저자가 실제로 겪은 것
저자가 현재 판단하는 것
외부 확인이 필요한 것
조사 결과에 따라 수정될 수 있는 범위
```

외부 자료가 저자의 경험을 대신하거나, 자료가 많은 쪽으로 글의 중심을 바꾸지 않는다. 조사 결과가 선택 판단과 충돌하면 충돌을 숨기지 않고 판단의 적용 범위를 줄이거나 사용자에게 알린다.

## 3. 출처 경계

우선순위는 다음과 같다.

1. 공식 문서·원문·공공 통계
2. 논문·연구기관 보고서
3. 원 발언·원 인터뷰·원 사례
4. 신뢰 가능한 2차 설명

최신 제품 글은 발표문과 현재 도움말을 함께 본다. 베타·지역·플랜·권한·날짜 조건을 분리한다. 확인일을 내부 근거 기록에 남긴다.

출처가 확인한 범위보다 큰 문장을 쓰지 않는다. 상관관계를 원인으로, 특정 사례를 전체 경향으로, 계획을 실제 성과로 바꾸지 않는다.

완료 기준: 각 확인 주장에 최소 한 개의 적합한 출처가 연결되고 사실·해석·경험의 주체가 구분된다.

## 4. 조사 출력 경계

리서치 노트를 원고에 그대로 붙이지 않는다. Source Brief에는 다음만 넘긴다.

```yaml
research:
  needed: true
  claims_to_verify: []
  verified_claims: []
  limitations: []
  source_links: []
  checked_at: ""
```

원고에는 중심 판단에 필요한 수치·사실만 넣고, 기관명과 연구자 이름이 독자의 흐름을 끊으면 본문에서는 평범한 설명으로 줄이고 출처 영역에 남긴다.

## 5. 조사 관문 생략

순수 경험형 짧은 칼럼이고 외부 일반화가 없으면 이 관문을 생략한다. `조사하지 않음`은 미완료가 아니라 의도적 선택이다.

## 6. 사용자가 기존 글을 제공한 경우

이 스킬은 과거 글을 스스로 찾지 않는다. 사용자가 겹치지 않게 할 글을 직접 붙여 주면, 그 글의 중심 주장·도입 장면·대표 표현을 확인하고 새 글에서 다시 쓰지 않는다. 동의어로 바꿔 같은 주장을 되풀이하는 것도 겹치는 것으로 본다.

붙여 준 글이 없으면 중복 확인을 하지 않는다. 추측으로 제외 목록을 만들지 않는다.
