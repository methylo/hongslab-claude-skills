# 판단 파일럿

이 문서는 음성 Source Brief에서 곧바로 전체 원고를 쓸지, 짧은 방향 후보를 먼저 보여 줄지 판정한다. 목적은 승인 단계를 늘리는 것이 아니라 긴 원고를 쓰기 전에 잘못된 중심 판단을 버리는 것이다.

## 1. 직접 완성 조건

다음이 모두 맞으면 `direct-completion`으로 진행한다.

- 반복과 후반 정정이 한 중심 판단으로 수렴한다.
- 서로 다른 제목과 결론을 요구하는 후보가 없다.
- 원문에 실제 장면·관찰·판단 중 두 가지 이상이 있다.
- 외부 사실을 새로 확인하지 않아도 글의 핵심이 성립한다.
- 사용자가 `한 번에`, `바로 완성`, `알아서 끝까지`를 요청했거나 기본 짧은 칼럼이다.

2,000~3,000자라는 이유만으로 파일럿을 강제하지 않는다. 방향이 분명하고 사용자가 전체 원고를 요청하면 직접 완성할 수 있다.

완료 기준: Source Brief에 `judgment.selected` 하나와 `judgment.confidence: high`가 잠겼다.

## 2. 판단 파일럿 조건

다음 중 하나면 `judgment-pilot`을 사용한다.

- 같은 음성에서 서로 다른 중심 판단 두 개 이상이 성립한다.
- 어느 판단을 고르느냐에 따라 제목·도입·마무리가 달라진다.
- 중요한 블로그·기고문·대표 칼럼이고 사용자가 방향을 먼저 보고 싶어 한다.
- 중심 판단의 명확도가 `medium` 또는 `low`다.

주제만 여러 개이고 한 주제가 명백하게 우세하면 약한 후보를 억지로 세 개까지 만들지 않는다. 후보는 최대 3개다.

## 3. 후보 생성 규칙

각 후보는 다음 다섯 항목만 제공한다. 후보마다 `장점과 주의점`, 평가표, 추천 이유를 추가하지 않는다.

```text
후보 N. 제목
중심 판단: 한 문장
도입: 3~4문장
마지막 판단: 1~2문장
필요한 경험·근거: 있는 것만
```

사용자가 비교·추천도 요청했으면 모든 후보 뒤에 `추천: N번 — 이유 1~2문장`만 별도로 붙일 수 있다. 이 추천은 사용자 선택을 대신하지 않으며 전체 원고로 진행하지 않는다.

후보 사이에는 다음 중 최소 세 가지가 달라야 한다.

- 중심 판단
- 도입 장면 또는 문제
- 인과 흐름
- 사용할 경험·사례
- 마지막에 남길 현재 판단

제목만 바꾸고 같은 글을 세 번 제시하지 않는다. 원문에 없는 경험·극적 갈등·성과를 후보 차별화를 위해 만들지 않는다.

완료 기준: 각 후보가 다른 전체 원고로 이어질 만큼 의미가 분리되고, 원문 소유권을 위반하지 않는다.

## 4. 선택 관문

파일럿을 제시한 뒤 전체 원고를 쓰지 않고 사용자 선택에서 멈춘다. 사용자가 번호를 고르거나 두 후보를 합치라고 하면 다음을 잠근다.

```yaml
judgment:
  selected: ""
  selected_pilot_id: ""
  approved_opening_direction: ""
  approved_ending_direction: ""
  rejected_directions: []
  merge_constraints: []
```

필드명은 `analysis-schema.md` 5항의 Source Brief 템플릿을 따른다. 이 문서에서 별도 이름을 만들지 않는다.

두 후보를 합치더라도 중심 판단은 하나로 다시 쓴다. 선택되지 않은 후보의 좋은 문장을 몰래 섞지 않는다.

완료 기준: 선택된 방향 하나와 폐기·병합 경계가 기록됐다.

## 5. 파일럿 생략 요청

사용자가 `방향 제안 말고 바로 써줘`라고 하면 중심 판단이 하나인 범위에서 파일럿을 생략한다. 서로 양립하지 않는 판단이 있고 임의 선택이 사실·경험의 의미를 바꾸면 한 번만 선택을 묻는다.

## 6. 최종 역점검

전체 원고 뒤 다음을 확인한다.

- 제목·도입·본문·마무리가 선택 판단을 따른다.
- `rejected_directions`가 다른 표현으로 되살아나지 않았다.
- 파일럿 문장을 기계적으로 이어 붙인 봉합 흔적이 없다.
- 선택 방향을 강화하려고 원문에 없는 경험이나 수치를 추가하지 않았다.

하나라도 어긋나면 선택된 Source Brief를 기준으로 해당 구간만 고친다.
