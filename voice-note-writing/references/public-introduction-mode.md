# 공개 소개 글 모드

음성 글쓰기 스킬이나 ‘먼저 말하고 나중에 글로 만드는 방식’을 다른 사람에게 소개할 때 사용한다.

## 중심 판단

소개 글은 사용법을 안내하는 글이 아니라 다음 판단을 보여주는 글이다.

> 생각을 완성한 뒤 쓰는 대신, 정리되지 않은 말을 글의 재료로 삼으면 글쓰기의 출발점이 달라진다. 음성 글쓰기 스킬은 그 말을 요약하는 데서 멈추지 않고 글쓴이의 판단을 보존한 완성 원고로 만든다.

## 권장 흐름

1. **기존 방식의 막힘** — 주제·제목·구조를 먼저 정해야 해서 첫 문장에서 멈추는 상황
2. **만든 이유** — 생각이 정리될 때까지 기다리지 않고 먼저 말해보기로 한 판단
3. **기본 결과** — 음성 요약이나 메모가 아니라 제목과 문단을 갖춘 완성 글
4. **핵심 특징** — 경험·관찰·판단·편집 지시 분리, 반복·자기 수정 활용, 문맥 확실한 전사만 교정, 사용자 표현·온도 보존
5. **활용 뒤 변화** — 음성이 임시 메모에서 글의 첫 재료로 바뀐 현재 작업 방식

## 사용법 분량 가드

- 명령 예시는 최대 한 문장만 쓴다.
- 단계별 사용법, 메뉴, 기능 목록을 본문의 중심에 두지 않는다.
- 독자가 ‘어떻게 누르는가’보다 ‘왜 만들었고 무엇이 달라지는가’를 기억하게 한다.

## 차이 설명과 마무리 압축

차이는 기능 목록이 아니라 **글쓰기의 시작 순서**로 설명한다.

- 일반적인 글쓰기: 생각을 정리한 뒤 문장으로 옮긴다.
- 음성 글쓰기: 생각이 흩어진 상태에서 먼저 말하고, 반복과 자기 수정을 재료로 글을 정리한다.
- 스마트폰, 산책, 이동 중 발화는 사용자가 실제로 밝힌 경우에만 장면으로 쓴다.
- 비교는 한 문단 이내로 끝낸다. 같은 장점을 다음 문단과 마지막 문단에서 반복하지 않는다.

마지막은 본문 요약이나 장점 재설명이 아니라 **현재 달라진 행동과 결과**로 닫는다. 한두 문장이면 충분하다.

```text
오래 고민하기보다 먼저 말한다.
→ 말하면서 찾은 생각이 한 편의 글이 된다.
```

## 원문 소유권

- 사용자가 직접 “만들었다”, “활용한다”고 말했으면 1인칭 제작·활용 경험으로 쓸 수 있다.
- 확인되지 않은 사용 횟수, 시간 절감 수치, 반응, 성과는 만들지 않는다.
- 음성의 말순서를 복제하지 않고 `문제 → 제작 판단 → 작동 특징 → 현재 활용` 인과로 재배열한다.

## 최종 점검

- [ ] 첫 문단이 제품 기능 소개가 아니라 기존 글쓰기의 실제 막힘에서 시작한다.
- [ ] 기본 결과가 ‘완성 글’임을 분명히 썼다.
- [ ] 요약·STT 기능과 음성 글쓰기의 차이가 보인다.
- [ ] 반복과 자기 수정이 단서라는 특징을 포함했다.
- [ ] 사용법은 한두 문장 이내다.
- [ ] 마지막이 행동 촉구가 아니라 제작자의 현재 활용·판단으로 끝난다.
